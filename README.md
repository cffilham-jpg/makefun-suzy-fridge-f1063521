A Python 3.13 standard-library-only fridge roast. The program writes exactly one UTF-8 line to `entry.txt` without a trailing newline, validates it, and prints its SHA-256. Set `MAKEFUN_OUTPUT_DIR` to choose the output directory; the default is `out`, with a temporary-directory fallback if directory creation fails.

## Run it

```sh
python3 main.py
```
